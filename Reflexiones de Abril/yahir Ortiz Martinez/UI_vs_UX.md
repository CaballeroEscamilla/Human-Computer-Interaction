<h2>UI vs UX</h2>
        <h3>Yahir Ortiz Martinez</h3>
        <p>
            Based on previous classes, I believe UX focuses on the overall experience users have when interacting with the system. It encompasses usability, accessibility, efficiency, and user satisfaction.
        </p>
        <p>
            The system might have a search function that requires the therapist to remember the exact file ID or navigate through multiple menus and complex filters to find information. This creates frustration, wastes time, and results in a poor experience. The system will implement an <strong>intelligent search bar</strong> that allows the therapist to find the patient's file by simply entering their name or part of it.
        </p>
        <p>
            Also looking at this topic, UI focuses on the visual elements and interactivity of the system. It's about how information is presented to users and how they interact with it through buttons, menus, and forms. I believe that good UI should be aesthetic, intuitive, and facilitate user interaction with the functionalities designed by UX.
        </p>
        <p>
            The list of files could be presented in a table with columns of dense text without a clear visual design. Buttons to view file details or download a file could be small and difficult to distinguish. This makes it difficult for the coordinator to read, navigate, and interact with the information.
        </p>
        <p>
            In summary, <strong>UX</strong> is concerned with the overall experience and satisfaction of <strong>patients, coordinators, and therapists</strong> when interacting with the file system.
        </p>
