### 1. Reflection: UI vs UX

The concepts of User Interface (UI) and User Experience (UX) are often confused, but they focus in diferent things of system design. According to the article *"UX vs UI: What’s the Difference? (And How They Apply to WordPress)"*, UI is about the visual and interactive elements like buttons, menus or layouts. UX is more about the general feeling and experience of the user when use the system, including usability, accesibility and user satisfaction.

**UI example (from our project):**  
In our clinical record system, we made a clean and simple panel with intuitive icons so doctors can access patient data and documents. The use of color buttons (green for "save", red for "delete") is a UI desition that helps to make the interface easy to understand at first view.

**UX example (from our project):**  
When we designed the record update process, we see that doctors feel frustrated when they lose changes because of session timeout. To make UX better, we added confirmation messages for actions like edit personal data, fill forms, open documents, and before exit a form. This help to reduce mistakes and improve satisfaction by saving time and avoiding data lost.

**Final reflection:**  
The key diference is that UI focus on the look and the components function, and UX is about how efficient and confortable is the experience. Our project shows that even with a nice UI, we need good UX desitions to build a really useful system.
