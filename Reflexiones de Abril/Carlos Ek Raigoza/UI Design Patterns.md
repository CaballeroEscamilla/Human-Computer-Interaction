### 3. Reflection: UI Design Patterns

In our project, we identify that one of the most important tasks for doctors was to find pacient information fast. To solve this, we applied the UI design pattern "Search and Filter".

**Example of implementation:**  
We designed a search bar and filter options in the pacient list. The user can write the pacient name or select filters like treatment type or activity status. This pattern is common in systems with large data, and we adapted it for medical use.

**Relevance to usability:**  
This pattern helps to find relevant data quickly and reduces the time wasted reviewing long lists. It also helps to avoid mistakes like opening the wrong pacient record. We used icons and a clear layout to make the filters intuitive and visible.

**Final reflection:**  
The implementation of the "Search and Filter" pattern improved usability by reducing friction in one of the most repetitive tasks in the system. This case shows how using a known UI solution, adapted to the medical context, can make the user experience more eficient and satisfactoy.
