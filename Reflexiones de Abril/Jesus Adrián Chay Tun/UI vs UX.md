### UI vs UX

When we talk about UI and UX, both are a bit weak in our case and sometimes hard to tell apart. Still, we try to work on both and give something useful on each side.

For the first example, we worked on screen adaptability (a UX element). This helps users feel comfortable and easily find what they need. Important things like the therapist area, patients, and calendar for appointments or activities are shown clearly on the screen, so users don’t have to make too many clicks or moves. The system (or the mockup) shows everything important on just one screen. But if we look at this from a UI point of view, we also chose a simple and clear font. This helps users read easily, although it depends on each person and needs to be tested.

For the second example, we can look at the parts of the mockup screen. Things like patients, schedules, and therapists are easy to see and understand. For example, there is a button that says “therapist” so users can know where to click. This is part of the UX because it helps users understand what each part does. Now, from the UI side, some buttons also have icons (like home, calendar, and patients). These icons help users know what the button does without reading, which is good, especially in the appointment area or first-time contact. This helps users who may not know much about technology or have low education levels to more easily identify the elements presented on the screen.

In general, even if UI and UX are similar in some ways, they are different. But they work together and are important to create a system that is easy and friendly for users.
